# Mohan Kumar M V — Portfolio

A responsive professional portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. After GitHub Pages finishes deploying, the site will be available at:
   https://mohankumarmv.github.io/Mohan-Porfolio-/

## Personal details to add
- Professional email address
- LinkedIn profile URL
- Resume PDF (add it to the repository root and link it from the page)
- Any verified project repository/demo URLs

The portfolio intentionally distinguishes completed experience from skills and certification topics that are still being studied.
